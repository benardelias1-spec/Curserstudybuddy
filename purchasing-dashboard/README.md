# Purchasing Dashboard

Front-end implementation of the “Purchasing Dashboard” design (React + TypeScript + Vite + Tailwind).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- **UI stack**: Tailwind v4 (via `@tailwindcss/vite`), `lucide-react` icons, `recharts` for charts.
- **Data**: Mocked in `src/App.tsx` for now.
